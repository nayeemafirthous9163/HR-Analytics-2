# HR-Analytics-2
An interactive Power BI analytics dashboard that tracks recruiting quality metrics, staff retention, hiring trends, and separation dynamics.

OVERVIEW OF THE PROJECT

An end-to-end HR analytical solution is provided by this Power BI project, which assesses employee onboarding, active workforce distributions, turnover trends, and metrics related to problematic hiring across job categories, age demographics, and locations.

KEY FEATURES

1. New Hires & Growth Analysis: Monthly new hire volume, YoY growth trends, age group variance, and demographic breakdowns are all represented graphically.
2. Active Employees vs. Separation: YoY regional growth, regional separation trends, voluntary vs. involuntary separation grounds, and active employee counts are all covered in detail.
3. Problematic Hires Tracking: Comprehensive analytics tracking monthly YoY fluctuations, age group percentages, gender, and regional breakdown metrics for problematic hires.
4. The score card for new hires: A dedicated performance view that examines new recruits based on VP executive filters, pay type distributions (salaried vs. hourly), and employment type (full-time vs. part-time).

TECH STACK & TOOLS USED

1. Business Intelligence: Microsoft Power BI Desktop
2. Data Transformation & ETL: Power Query (ETL pipeline, Data Cleaning, attribute transformations)
3. Data Modeling & Calculations: DAX (Data Analysis Expressions) for custom measures, YoY variance calculations, and growth rates.

HOW TO RUN/OPEN TEH PROJECT

1. Prerequisites: Install [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/) on your Windows machine.
2. Download: Download the project file (`.pbix`) or extract the repository archive.
3. Open: Double-click the `.pbix` file to open it directly in Power BI Desktop.
4. Interact: Click on interactive slicers, VP filters, and chart elements to dynamically explore cross-filtered reports.
